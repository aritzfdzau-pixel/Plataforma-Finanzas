# Plataforma-Finanzas

Terminal financiero personal de estudio: operativa (cálculos, históricos, escenarios)
alimentada por una base de conocimiento propia (fichas), más divisas y noticias.
100 % online: GitHub + GitHub Pages. HTML + CSS + JS vanilla, sin dependencias.

- Normas: [`AGENTS.md`](AGENTS.md)
- Plan por fases: [`PLAN.md`](PLAN.md)
- Decisiones: [`decisiones.md`](decisiones.md)
- Plantilla de ficha: [`conocimiento/_plantilla.md`](conocimiento/_plantilla.md)

Tests: `node --test` (se ejecutan solos en cada pull request).

Probar la web en local: desde la raíz del repo, `python3 -m http.server 8000` y abrir
`http://localhost:8000/web/`.

> Herramienta de estudio; resultados orientativos. Sin datos de clientes ni de ningún banco.
